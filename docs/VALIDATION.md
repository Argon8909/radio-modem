# Проверка первого прототипа

Дата: 21 октября 2026. Проверки проведены в Linux cloud environment; реальных микрофона, Android и радиостанций здесь нет.

- `npm test`: 20 тестов выполнены, 20 пройдены, пропусков нет.
- `npm run measure`: 104 из 104 сообщений обнаружены и восстановлены с верной CRC в заданных сценариях. Для каждого из 13 смещений (0, ±10, ±25, ±50, ±80, ±150, ±300 Гц) выполнено 8 передач с фиксированными seed. AWGN SNR=10 dB относительно мощности активного сигнала при 8 кГц. Текст: «Привет, эфир!». PER=0 в этой выборке; средняя абсолютная ошибка финальной оценки AFC для отдельных смещений 0,045…0,125 Гц. Это результат синтетического канала с конечной выборкой, не оценка надёжности реальной связи.
- Chromium + Playwright: кнопка самопроверки, WAV как виртуальный микрофон со сдвигом +80 Гц, захват через AudioWorklet и Worker, приём русского текста с CRC, воспроизведение из интерфейса, контроль лимита UTF-8. Проверены повторное включение микрофона и прерывание передачи без записи о её завершении. Проверены мобильная ширина 393 px без горизонтального скролла, сохранение в IndexedDB, восстановление журнала/настроек и запуск микрофона после перезагрузки без сети.

Алгоритм и параметры стенда сохранены в `test/` и `tools/measure.mjs`; браузерный сценарий — `tools/browser-check.mjs`. У тестового виртуального микрофона нет акустических отражений, реального шумоподавления телефона и нелинейностей динамика. Следующий приёмочный тест — обмен BASE↔FIELD на реальных ноутбуке и Android по инструкции README, затем отдельный радиотракт.
