# Внешние зависимости

У приложения нет сторонних JavaScript-библиотек, CDN, внешних шрифтов, SDK и ресурсов, необходимых для работы. Модули написаны для этого проекта на основе общеизвестных методов CPFSK, Goertzel, CRC и оконной sinc-интерполяции. Требуются стандартные Web Audio, AudioWorklet, Worker, IndexedDB и Service Worker API.

Node.js (MIT и лицензии включённых компонентов) используется только как инструмент разработки, сервер и тестовый раннер; не встраивается в браузерное приложение.

Для необязательных интеграционных тестов используется Playwright 1.64.1 и его playwright-core той же версии, Apache-2.0: https://github.com/microsoft/playwright/blob/main/LICENSE. Устанавливается отдельно в игнорируемый `.local/browser` или системный temp. Chromium — внешний тестовый браузер с лицензиями Chromium и включённых компонентов; не распространяется в составе приложения. Браузерные тесты не добавляют зависимостей обычному пользователю страницы.

mkcert (BSD-3-Clause) и ADB (Apache-2.0 и лицензии компонентов) упомянуты как необязательные внешние инструменты доступа к локальной странице с Android; проект их не включает и не устанавливает.
